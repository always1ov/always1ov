做个人网站最容易犯的错，是把所有喜欢的东西都放进去：渐变、毛玻璃、卡片阴影、悬浮动画、暗色霓虹。每一个单看都不错，加在一起就成了一锅什么都有的粥——看不出重点，也看不出人。

这个站的做法是反过来：**先定死能用什么，剩下的一律不用。**

## 两种颜色

整站只有一个彩色：`#ff4a2b`，朱砂红。

它出现在：正文选中、链接下划线、代码里的关键字、条目的悬停填色、首页那枚方块。除此之外，全部是黑白灰。

```css
--bg:     #0b0b0c;   /* 夜 */
--fg:     #e9e4da;   /* 暖白，不是纯白 */
--accent: #ff4a2b;
```

暖白（`#e9e4da`）而不是纯白（`#ffffff`），是因为纯白在深色背景上会「发光」，长文读起来眼睛累。暖一点，像纸。

## 三种字体，各司其职

| 用途 | 字体 | 为什么 |
|---|---|---|
| 标题 | Instrument Serif + 中文衬线 | 高对比衬线撑得住大字号 |
| 正文 | Instrument Sans + 系统中文黑体 | 中文小字号下衬线在部分系统里会糊 |
| 元信息 | JetBrains Mono | 等宽让日期、字数天然对齐 |

中文没有加载网络字体。一套中文字体动辄 3~8 MB，为了好看一点让所有人多等两秒，不划算。系统字体里的苹方、鸿蒙、微软雅黑都够好。

拉丁字母则用了 Google Fonts 上的 Instrument 家族——它总共不到 100 KB，而标题的性格几乎全在这上面。

## 留白是有层级的

页面上任何两个元素之间的距离，都在说「这两个东西的关系有多近」。所以：

- 标题**上方**的空白，永远远大于下方——它属于下面的内容，不属于上面的
- 段落之间是 `1.5em`，一节和一节之间是 `2.6em`
- 中文行高给到 `1.85`，比英文排版的常规值高，因为方块字没有上下伸出的笔画来制造视觉间隙

这些数字不是调出来的好看，是有依据的。调到「感觉对了」为止，通常意味着下一次会调到别的数字。

## 那条线

首页背后那片东西不是图片，是当场画出来的。

几百根笔画从随机的位置出发，每走一步就去问一次噪声场「往哪走」，然后一直走下去，中间不抬笔。

```ts title=theme/components/HeroLine.vue
// 噪声值 → 角度。步长要远小于噪声格，笔画才会「流」而不是「抖」
const angle = noise(p.x / cell, p.y / cell) * Math.PI * 3
p.x += Math.cos(angle) * step
p.y += Math.sin(angle) * step
```

随机种子是当天的日期。所以：

- 同一天来的人，看到的是**同一张**图
- 不同的日子来，看到的是**不同**的图
- 点一下「重画」，能看到这片场里的另一种可能

选它当作站点的标志，是因为一条不抬笔的线正好就是 always 的字面意思。装饰如果只是装饰，就不该存在；它得说点什么。

::: info 关于动效
所有动画都听 `prefers-reduced-motion`。开了减弱动态效果的人，看到的是一张一次画完的静态图。
:::

## 条目行

文章列表是这个站唯一一个「有交互」的部件：鼠标移上去，朱红色从左边刷过去，文字反白，右边浮出一个箭头。

它满足两个条件才留下来的：

1. 它让「这一行是可以点的」这件事变得明显——这是功能，不是装饰
2. 它只用了已有的颜色，没有引入新东西

任何一个动效，如果两条都不满足，就不该加。
