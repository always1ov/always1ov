## 写这里的人

我是 **always1ov**。写代码，也写字——在我这儿这是同一件事：把一堆混乱的东西，整理成一个能被别人复用的秩序。

平时的兴趣大致是：怎么把复杂系统讲清楚、排版和字体、以及那些「明明可以更简单」的工程问题。

如果你想聊点什么，最快的方式是[写封邮件](mailto:always1ov.g@gmail.com)。我不一定回得快，但会认真读。

## 关于这个站

这是我自己的网站。不是博客平台上的一个账号，是一个我自己能改到每一个像素的地址。

它没有评论区、没有访问统计、没有 cookie 提示——因为没有 cookie。你在这里读到的东西不会被记录，也不会被推荐给谁。

- **写作**：[全部文章](/posts/)，更新很慢
- **订阅**：[RSS](/atom.xml)，最原始也最可靠的方式
- **搜索**：任意页面按 <kbd>⌘</kbd> <kbd>K</kbd>（Windows 上是 <kbd>Ctrl</kbd> <kbd>K</kbd>），或者直接按斜杠

## 这个站是怎么造的

框架用的是 [Valaxy](https://valaxy.site)（Vue 3 + Vite）。但主题不是装来的——是这个仓库里的 `theme/` 目录，一行 CSS 一个组件写出来的，叫 `valaxy-theme-always`。

| 部件 | 用的什么 |
|---|---|
| 框架 | Valaxy（Vue 3 + Vite） |
| 主题 | `valaxy-theme-always`，自己写的，就在本仓库的 `theme/` 里 |
| 部署 | GitHub Actions → Cloudflare Pages |
| 源码 | [github.com/always1ov/always1ov](https://github.com/always1ov/always1ov) |

想知道细节的话，我写过两篇：[给 Valaxy 写一个只属于自己的主题](/posts/valaxy-custom-theme/)，还有[这个站长这样，是有原因的](/posts/design-notes/)。
